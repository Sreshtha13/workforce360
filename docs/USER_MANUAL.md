# User Manual — Workforce 360 ERP (MVP)

Audience: **Employees**, **Managers**, and general staff.

## Getting started

1. Open your organization's Workforce 360 URL (e.g. `https://app.yourcompany.com`).
2. Sign in with email/password or **Sign in with Google** (if enabled).
3. Complete MFA if prompted (authenticator app or backup code).

## Dashboard

Your home dashboard shows widgets relevant to your role (attendance summary, pending approvals, notifications).

## Employee portal

| Area | What you can do |
|------|-----------------|
| **Attendance** | Clock in/out, view history |
| **Leave** | Request leave, track balance |
| **Assets** | View assigned assets |
| **Documents** | Upload/download personal documents |
| **Payslips** | Download published payslips |
| **Helpdesk** | Submit and track support tickets |

## Approvals

If you are an approver, open **Approvals** to act on leave, invoices, reimbursements, and other workflow items.

## Profile & security

- Update profile from the user menu (where permitted).
- Enable MFA under account security settings.
- Manage trusted devices from auth settings.

## Getting help

Contact your internal HR or IT administrator. Administrators can reference the Admin Manual for configuration issues.
