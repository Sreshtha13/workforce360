## TC-001 — API health endpoint returns healthy status

**Module:** Infrastructure  
**Feature:** Health & API Docs  
**Scenario Type:** Positive / API  
**Priority:** Critical  
**Severity:** High  

**Preconditions:**
- API server is running on configured port (default `http://localhost:4000`)
- Database is connected and seeded

**Test Data:**
- None

**Steps to Execute:**
1. Send `GET /api/health` with no authentication headers.
2. Inspect HTTP status code.
3. Inspect response JSON body.

**Expected Result:**
1. Request completes without error.
2. HTTP status is `200`.
3. Response envelope is `{ data: { status: "ok" or similar, database: connected }, error: null }`.

**Postconditions:** None

**Notes / Dependencies:** Confirmed from `healthController.getHealth` and `app.integration.test.ts`.
